## Как устроен файл

Одна HTML-страница без сборки и зависимостей, шрифты — из Google Fonts. Контент лежит в массивах в начале `<script>`:

| Массив | Что в нём |
|---|---|
| `LESSONS` | уроки (HTML); `data-widget` подключает калькулятор |
| `QUIZ` | вопросы теста: `m` — урок, `c` — индекс верного ответа, `w` — объяснение |
| `CASE`, `CASE_OPTS` | кейс «Разбор кабинета» |
| `PLAN` | план на 21 день |
| `VACS`, `GAP`, `ROUTES`, `QA` | вакансии, анализ пробелов, пути к опыту, вопросы собеседования |
| `REVIEWS`, `GLOSS` | отзывы для тренажёра, словарь |

Калькуляторы и тренажёры с ИИ описаны в объекте `W`: `unit`, `stock`, `ads`, `promo`, `card`, `review`.

Чтобы обновить тарифы, отредактируйте тексты уроков и значения по умолчанию в калькуляторах. Затем переопубликуйте артефакт и закоммитьте изменения.
